# ALT-RFID-SAMPLES

Project
* **`NewGen2XPlay` (Android):** Full Android sample project featuring source code, UI resources, and Gradle build tooling.
* **`NewGen2XPlay iOS` (iOS):** Complete iOS project containing application source, resources, and bundled Zebra Gen2X XCFramework binaries.

Overview
- The NewGen2xPlay sample application is provided solely for demonstration purposes to showcase the features of Impinj Gen2X extensions.
